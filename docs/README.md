# LocalFlow iOS support and privacy pages

Static, dependency-free GitHub Pages content. No scripts, cookies, analytics, external fonts, or remote assets.

Planned URLs:
- Support: https://ajbarryiii.github.io/LocalFlow/
- Privacy: https://ajbarryiii.github.io/LocalFlow/privacy.html

Preview with `python3 -m http.server 8765 --directory docs`.

Before publishing, the owner must review the privacy text. Configure GitHub Pages to deploy the `/docs` folder from an approved branch; after the PRs are merged, use `main` as the source. No repository release/signing workflow changes are needed. The existing `website/` is unrelated and remains unchanged.
