# LocalFlow iOS support and privacy pages

Static, dependency-free GitHub Pages content. No scripts, cookies, analytics, external fonts, or remote assets.

Public URLs:
- Support: https://ajbarryiii.github.io/LocalFlow/
- Privacy: https://ajbarryiii.github.io/LocalFlow/privacy.html

Preview with `python3 -m http.server 8765 --directory docs`.

The owner approved the policy on October 14, 2026. GitHub Pages publishes the repository root of the dedicated `gh-pages` branch. That branch contains only `index.html`, `privacy.html`, `styles.css`, and `.nojekyll`, copied from this directory. Publish future approved website changes by updating those files on `gh-pages`; do not publish unreviewed policy changes. Keeping a dedicated publication branch avoids tying the public URLs to a temporary PR branch.

No repository release/signing workflow changes are needed. The existing `website/` is unrelated and remains unchanged.
