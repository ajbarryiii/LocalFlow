Support

LocalFlow is an offline dictation app and custom keyboard for iPhone, requiring iOS 26 or later.

Setup

  1. Open LocalFlow and complete onboarding, including microphone permission and local model preparation.
  2. In Settings > General > Keyboard > Keyboards, add LocalFlow and enable Allow Full Access so the keyboard can communicate with the app on your device.
  3. In a supported text field, select the LocalFlow keyboard and tap its microphone. If needed, it opens LocalFlow to start the microphone; return to the text field as prompted.
  4. Finish dictation to insert text. Start a Flow session to keep dictation ready between apps, and use End session when finished.

Common questions

Why is the microphone indicator still on? An active Flow session keeps the microphone ready. Audio between dictations is discarded. End session stops capture; the configured idle timer also ends a session.

Why is the keyboard unavailable? Password and certain other fields use the system keyboard. Apps can also disable custom keyboards.

Why is there no inserted text? Check microphone permission and Full Access, complete model preparation, and try a short dictation in Notes. Locking during dictation cancels that dictation.

Report a problem

In LocalFlow, choose Report a bug > Write email. Or email localflow@wildernesslabs.ai directly. Include the steps to reproduce, expected result, actual result, app version, iOS version, and device type. Avoid including passwords, sensitive text, or personal recordings. No recordings, transcripts, or logs are attached by the app automatically.
